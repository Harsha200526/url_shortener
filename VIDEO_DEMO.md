## What the Demo Covers

1. Landing page walkthrough
2. User registration & login (JWT + bcrypt authentication)
3. URL shortening with custom alias
4. Short URL redirection (302 redirect)
5. Dashboard with click stats
6. Analytics page with charts (Recharts)
7. QR code generation & download

## Tech Stack Used

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js
- **Database**: MongoDB Atlas with Mongoose ODM
- **Auth**: JWT + bcryptjs
- **Analytics**: ua-parser-js for browser/device/OS tracking
